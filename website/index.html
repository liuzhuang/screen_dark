Mac 多显示器黑屏工具

Mac 黑屏不休眠，
任务继续跑。

锁屏可能中断 Codex、Claude Code 和 Computer Use；调暗内建屏幕，外接显示器却往往还亮着。ScreenDark 不主动锁屏，只让选中的内建或外接显示器变暗；全部显示器变暗时会阻止空闲系统睡眠，帮助当前任务继续运行。

安装 ScreenDark

使用方法

一键黑屏，再一键点亮。

  1. 1

    选择需要黑屏的显示器

    点击内建或外接显示器，可分别控制。

  2. 2

    按快捷键点亮全部显示器

    按下 ⌃⌥⌘B，恢复各屏此前的亮度。

显示器变暗不等于锁屏。

显示器变暗期间会阻止空闲系统睡眠，但不会阻止别人操作 Mac，请仅在可信环境中使用。

安装

从源码安装。

ScreenDark for Mac

运行安装脚本

获取源码后，在项目根目录运行：

bash reinstall.sh

需要 macOS 13+ 和 Xcode Command Line Tools。脚本会构建 Release、安装到 ~/Applications 并自动启动。
